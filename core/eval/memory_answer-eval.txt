# 记忆作答维度评测集：格式为 维度|问句|期望|记忆原文
#
# **这个维度测的是"用户实际听到的那句话对不对"**，
# 而记忆召回维度测的是"正确答案有没有出现在前 K 条里"。
# 两者的差别在实测里很具体：13 条样本上 Recall@6 = 100%，
# 而排序第一条答对的是 12/13 = 92.3%。
#
# **为什么单独一个文件而不是复用记忆召回的样本**：
# 记忆召回与记忆作答的**期望值口径不同** ——
# 召回期望的是"命中"这个事实，作答期望的是"说对了内容"这个事实。
# 共用文件就得让执行器按维度分支，那会让"一条评测样本的期望值"
# 变成一个随维度变化的字段，报告里说不清每个维度到底在比什么。
#
# 记忆原文与问句必须是**不同表述** ——
# 相同表述下作答正确率必然是 1.0，测到的是字符串相等而不是语义能力。
#
# ============================ 两组样本 ============================
#
# **第一组（13 条）：答得上的问题** —— 期望系统给出指定的那条记忆。
# 记忆原文与问句不同表述，测的是语义检索 + 作答口径的正确性。
MEMORY_ANSWER|我奶奶家在哪里|ANSWERED|我奶奶住在苏州
MEMORY_ANSWER|我家养了几只小动物|ANSWERED|我养了三只仓鼠
MEMORY_ANSWER|我最爱的菜是什么|ANSWERED|我最爱吃酸菜鱼
MEMORY_ANSWER|我接下来有什么安排|ANSWERED|我下个月要参加同学的婚礼
MEMORY_ANSWER|我有什么害怕的东西吗|ANSWERED|我怕黑
MEMORY_ANSWER|我写字用什么手|ANSWERED|我习惯用左手写字
MEMORY_ANSWER|我表姐在哪个城市工作|ANSWERED|我表姐在南京工作
MEMORY_ANSWER|我的年龄是多少|ANSWERED|我今年三十五岁
MEMORY_ANSWER|我一般什么时候去健身|ANSWERED|我每周三去健身房
MEMORY_ANSWER|我有什么饮食禁忌吗|ANSWERED|我对芒果过敏
MEMORY_ANSWER|我岳父有什么爱好|ANSWERED|我岳父喜欢下棋
MEMORY_ANSWER|我的车是什么颜色|ANSWERED|我的车是白色的
MEMORY_ANSWER|我最近在忙什么|ANSWERED|我正在准备考研
#
# **第二组（12 条）：答不上的问题** —— 记忆库里**根本没有**对应事实。
# 期望系统**不编造**，如实说"没有记录"。
#
# **为什么必须有这一组**（这是本维度最关键的设计）：
# 只测"答得上的问题"时，**永远拒答**的系统也能拿满分 ——
# 门禁形同虚设。加了这一组之后，"拒答"才第一次有了可衡量的价值：
# 对答不上的问题拒答 = 正确；作答 = 编造（机器人说了库里没有的事）。
#
# **这两组的期望值不同，所以格式也不同**：
# 第二组用 5 段 —— 维度|问句|期望|记忆原文|期望记忆原文，
# 第四段与第五段都留空：
#   - 第四段留空 = 这条样本**不向记忆库写入任何内容**；
#   - 第五段留空 = "库里没有这条记忆"，期望系统<b>拒答</b>。
# 第五段留空是必要的：它让"答不上"与"答错了"在数据上可区分。
#
# **这 12 条与阈值推导用的留出集完全不重合** ——
# 留出集负责**推导**阈值，这 12 条只负责**验收**。
# 用同一批数据既推导又验收，等于自己给自己判卷。
#
# 第五段留空 = 期望拒答（库里没有这条记忆）。
# 第四段也留空 = 这条样本**不向记忆库写入任何内容** ——
# 否则"库里没有答案"的前提就被自己破坏了。
