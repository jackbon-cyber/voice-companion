# 端侧识别评测集（Python 侧执行）
#
# 格式：维度|噪声条件|参考文本
#
# 用法：把每条参考文本合成为带噪音频（16 kHz 单声道 16-bit PCM），
#       送入 faster-whisper 识别，计算字符错误率（CER）与词错误率（WER）。
#
# 噪声条件说明：
#   clean    —— 无噪，信噪比 30 dB
#   mild     —— 轻度环境噪声，信噪比 20 dB
#   noisy    —— 中度环境噪声，信噪比 10 dB
#
# 参考文本刻意避开意图原型示例句与记忆关键词，保证与训练语料不相交。
# 同一个参考文本在不同噪声条件下重复出现，是有意的：
# 它衡量的是同一条内容在不同信噪比下的识别稳定性。
