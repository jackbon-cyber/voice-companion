# 端侧识别评测集（Python 侧执行）
#
# 格式：维度|噪声条件|参考文本
#
# 用法：把每条参考文本合成为带噪音频（16 kHz 单声道 16-bit PCM），
#       送入 faster-whisper 识别，计算字符错误率（CER）与词错误率（WER）。
#
# 噪声条件说明：
#   clean    —— 无噪，信噪比 30 dB
#   mild     —— 轻度环境噪声，信噪比 20 dB
#   noisy    —— 中度环境噪声，信噪比 10 dB
#
# 信噪比按**语音段功率**定标（见 core/eval/edge_eval.py 的 speech_signal_power），
# 而不是整段功率 —— TTS 合成音首尾有大段静音，用整段功率会让标称值与实际脱节。
#
# 参考文本刻意避开意图原型示例句与记忆关键词，保证与训练语料不相交。
# 同一个参考文本在不同噪声条件下重复出现，是有意的：
# 它衡量的是同一条内容在不同信噪比下的识别稳定性。
#
# 每个条件的样本量都必须达到 MIN_SAMPLE_SIZE（10 条），否则该条件不参与门禁判定 ——
# 样本不足时的准确率不具统计意义，拿它当门禁依据等于让随机波动决定成败。
