# 真人录音目录

端侧识别（ASR）评测的**真人录音**放在这里。

## 为什么需要真人录音

评测原本只有一种音频来源：TTS 合成。合成音缺少真人的音高变化、
共振峰细节与语速波动，属于 Whisper 的**分布外输入**：

- `clean` 条件的准确率**偏乐观**，不能作为真机指标；
- `mild` / `noisy` 条件测的是"噪声下能不能识别"，
  而合成音在噪声下的表现既不代表真人语音、也不能用来判定模型能力，
  因此**不参与门禁判定**，只作为趋势参考。

换成真人录音后，三个噪声条件**全部参与门禁判定**，
数字才真正代表真实用户在真实环境下的体验。

## 怎么放录音

### 1. 录什么

把 `core/eval/asr-eval.txt` 里的**参考文本**逐条朗读一遍。
文本共 14 条（clean / mild / noisy 三个条件用的是同一批文本），
所以只需录 14 条音频。

### 2. 录成什么格式

| 项目 | 要求 | 原因 |
|---|---|---|
| 格式 | WAV | 无损、无解码依赖 |
| 采样率 | 任意（评测会自动重采样到 16 kHz） | —— |
| 位深 | 16-bit | 只支持 16-bit |
| 声道 | 单声道 | 只支持单声道 |
| 文件名 | 见下 | —— |

### 3. 文件名

**不要自己起名** —— 用脚本生成，否则哈希对不上，评测找不到。

```powershell
F:\tools\python313\python.exe -m core.eval.audio_source --list
```

会列出每条参考文本对应的文件名，例如：

```
今天天气真不错            -> recording_3f8a1c2d9e0b4a56.wav
我最近在准备期末考试       -> recording_7c1d9e0b4a563f8a.wav
```

把录好的音频按这些名字放进本目录即可。

### 4. 验证

```powershell
F:\tools\python313\python.exe -m core.eval.audio_source --check
```

会报告覆盖了多少条参考文本。

## 录制建议

这些建议直接影响数字的可信度：

- **用真人朗读，不要念稿式的平板语调** —— 平板语调会让准确率虚高；
- **正常语速**，不要刻意放慢或加快；
- **安静环境录音** —— 评测的噪声条件是**程序叠加**的，
  录音里自带的环境噪声会与叠加噪声混在一起，标称信噪比失真；
- **读完即可**，前后留 0.5 秒静音即可（评测会自行切分语音段）；
- **同一人朗读全部 14 条** —— 不同人的音色差异会让准确率波动，
  混着录无法归因。

## 隐私

录音是特定人员的语音数据，**不入库**（见 `.gitignore`）。
本目录只保留说明文件与目录结构。
